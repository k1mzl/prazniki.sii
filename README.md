# prazniki.sii

Ta mapa vsebuje preprosto statično spletno aplikacijo za prikaz praznikov in označevanje datumov.

## Datoteke

- `index.html` - glavni vmesnik aplikacije
- `styles.css` - stilni predlog za koledar in seznam praznikov
- `script.js` - logika koledarja, izbiranja datuma in iskanja

## Kako uporabljati

1. Odpri `index.html` v brskalniku.
2. Preklapljaj med meseci s puščicami.
3. Klikni na kateri koli datum, da ga označiš in prikažeš podrobnosti.
4. V iskalno polje vpiši ime praznika, da filtriraš seznam.

## Funkcionalnosti

- pregled koledarja
- označevanje izbranega datuma
- prikaz slovenskih praznikov
- iskanje po praznikih
- prijazen mobilni izgled
